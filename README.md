# Position Sizing v1.0

Multi-asset position sizer and stepped compounding planner. Single static `index.html`, runs entirely in the browser (no backend, no data stored).

## Deploy to Netlify

1. Netlify → **Add new project → Import an existing project → GitHub** → pick `dewatagiri/position-sizing`.
2. Build command: *(leave empty)*. Publish directory: `.` (already set in `netlify.toml`).
3. Deploy.
